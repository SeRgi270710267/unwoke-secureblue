Web

A site looks broken

Keep locked Banking and boring sites should work. Games, WebGL maps, extension stores, and some SPAs will not. That is the lock. Fast path: ujust why.

  1. Name the symptom

    Blank canvas / maps / 3D → isolation (WebGL/WebGPU). “This page needs JIT” / broken editors → JIT-less. No password save → hardening pack. Cannot install an extension → extension block (keep it). Cookies vanish on Trivalent → network sandbox.

  2. Change one pack, then restart the browser

    ujust why
# or, only the one you need:
ujust set-brave-jitless off
ujust set-brave-isolation off
ujust set-brave-hardening off
ujust set-trivalent-network-sandbox off

    Trivalent aliases exist as set-trivalent-* for the same packs. Origin GPU/audio dead is Bubblejail, not JIT.

  3. Do not flatten the profile

    Turning every pack off to watch one video is how you recreate stock Chrome. Leave extensions blocked. Leave hardening on if you only needed WebGL. DevTools stay allowed unless you lock them.

Need a tighter house browser than Origin? Rebase to *-trivalent (Vanadium patches + trivalent_t). Need no image browser? Browserless, then you still should not install a random Firefox. Extra packs vs looking like stock Trivalent: Fingerprinting vs locks. See FAQ.
