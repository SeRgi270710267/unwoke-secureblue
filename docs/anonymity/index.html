Vs Tails · Whonix · Qubes

Hide the IP in Whonix. Keep this OS locked.

Unwoke does not route your desktop through Tor. That would break updates and is not Whonix. Anonymity here means: official Whonix VMs when you need Tor, plus a few host leaks we can close without turning off SELinux, Safe Browsing, or NTS.

Not Tails Not host Tor No security cut

If you need to be hard to name

01 · Persistent Tor

Whonix on this box

ujust install-whonix then ujust start-whonix. Work only in Workstation. Same Google account on Trivalent on the host still names you. How-to: Whonix KVM.

02 · Hostile PC

Boot Tails

Hotel laptop, border search, leave no disk. That is a USB OS, not an overlay. Unwoke cannot fake amnesia.

03 · Split lives

Qubes-Whonix

Different computer. Xen, not KVM on Unwoke. Highest stack; you leave this OS.

Host wins we did ship (no Tor)

LeakDefaultRevert
DHCP hostname / DUID Not sent ujust set-dhcp-hostname on
TCP timestamps (clock skew) Off (Kicksecure-style). Does not disable NTS. ujust set-anon-net on
Local hostname still “fedora” Unchanged (printers). Opt-in host ujust set-anon-hostname on / off
MAC on café Wi‑Fi Leftover stock ujust toggle-mac-randomization
Disk leftovers Volatile journal, no hibernate ujust set-disk-traces on

We did not add host Tor, UTC-by-default, kloak, or a fake machine-id. Those either break security, break the desktop, or make you more unique.
