FAQ

This page is only Unwoke SecureBlue. Stock secureblue questions (rollback, USBGuard, kargs, Trivalent, …) live in the mirrored secureblue FAQ, which updates daily from their repo.

Are you affiliated with secureblue?

No. Personal overlay. Their project is secureblue.dev. Use that if you want the official images, Trivalent, Bazaar, and the Contributor Covenant. Our conduct is the opposite of that document.

Is this more secure than stock secureblue?

Origin images: no. Stock + Trivalent is tighter. Browserless images: tighter than Origin because there is no fat brave_t and no Chromium in the image. That only lasts until you install a browser. It is not “safer than Trivalent while browsing.”

What is the browserless flavor?

Same overlay: Trivalent, Bazaar, and GUI stores are gone. Unlike the default images, we do not install Brave Origin, do not load brave_t, and do not add Flathub. Rebase to unwoke-silverblue-browserless (or kinoite / nvidia-open variants).

Easy host browser installs are blocked until you opt in:

ujust set-allow-browsers on ALLOW

That unmasks common Flatpak browsers and drops the rpm-ostree exclude list. If Flathub was off, it switches the system remote to verified (not full). A random Firefox is usually worse than stock Trivalent. Toolbox, brew, AppImage, and rpm-ostree --disableexcludes are not blocked — this is a seatbelt, not a prison.

What is Brave Origin, and is it “full Brave”?

Brave Origin is a separate Linux package (brave-origin) with extras compiled out. Binary path: /opt/brave.com/brave-origin/brave. We do not install brave-browser. It is still Chromium-family software, not Trivalent.

Where is the software store?

There isn’t one. Bazaar, GNOME Software, and Plasma Discover are removed. Origin images add the Flathub-verified CLI remote (stock’s default). ujust set-flathub full or off to change it. Browserless images add nothing until ujust set-allow-browsers on ALLOW.

What ujust commands did you add?

Stock secureblue commands stay. Overlay extras, all reversible, are listed on Features. Short list:

ujust unwoke-status
ujust audit-unwoke
ujust set-flathub verified|full|off
ujust set-flatpak-lockdown on|off
ujust set-brave-hardening on|off
ujust set-brave-devices on|off
ujust set-brave-jitless on|off
ujust set-brave-extensions block|allow
ujust set-brave-bubblejail on|off
ujust set-unwoke-theme apply
ujust set-allow-browsers on ALLOW

A site broke after install

JIT-less is on by default on Origin. Turn it off and restart Brave Origin:

ujust set-brave-jitless off

Camera/mic/USB in the browser: ujust set-brave-devices off. Passwords/autofill: ujust set-brave-hardening off. Extensions: ujust set-brave-extensions allow.

Flatpaks do nothing / need a million permissions

Permission lockdown is on by default (stock ships it as opt-in). Grant per-app in Flatseal, or:

ujust set-flatpak-lockdown off

Wallpaper, lock screen, accent

Default Unwoke navy wallpaper, a darker lock image, dark style, GNOME named accent blue, GTK/KDE #3b6cff. Gallery: Brand. GNOME has no classic screensaver; the lock screen is that image. Re-apply: ujust set-unwoke-theme apply.

What is set-brave-bubblejail?

Optional extra sandbox around Origin’s desktop launcher. Default off. GPU, PipeWire, and portals may break. Turn it off if the window will not start.

Did you turn user namespaces back on?

Not globally. harden_userns stays on. On Origin images, Brave Origin is labeled brave_t and that domain is on secureblue’s userns allow-list. Browserless images do not add that exception — same as stock with Trivalent removed. Unconfined apps still cannot create user namespaces.

Why Unwoke SecureBlue that way?

Unwoke is the adjective/verb modifier. SecureBlue is one proper name (S and B capped), not “Secure Blue”. Repo and GHCR slugs stay lowercase because registries do.

How do updates work?

Not a git fork. CI pulls their signed image, verifies it with their public key, pins the digest, layers this overlay, and cosign-signs the result. Your machine follows ghcr.io/sergi270710267/… with rpm-ostree after the signed rebase. Rebuilds at 08:00 and 20:00 UTC.

Can I trust the signing key?

You can verify with cosign.pub in the repo. The private key is a GitHub Actions secret, not a YubiKey. That is weaker than a hardware key. It is stated on the home page on purpose.

How do I contribute?

This overlay: our GitHub and our conduct. Stock secureblue (Trivalent, their image recipes, their CoC): their mirrored contributing page. Do not send Unwoke patches to their repo or the other way around.

Where is the USB ISO?

The OS is the GHCR image. For a blank disk, install secureblue first, then rebase. Optional ISOs can be built from the iso workflow; GitHub will not host a 3 GB file as a normal release.
