Contributing

Same slot as on secureblue.dev. Two different projects. Do not mix the repos.

Unwoke SecureBlue

Issues and pull requests: github.com/SeRgi270710267/unwoke-secureblue. Our conduct, not their Covenant. No donate wallet. Useful patches and reproducible bugs beat essays. What the factory already auto-heals vs what must stay a human: Factory.

Maintainer merge only. Fork, PR, wait. pr-gate + canary must be green. SeRgi270710267 has the last word (often after a pass with Grok). There is no auto-merge. Green CI is not permission to land. CODEOWNERS is @SeRgi270710267 on every path.

Hard no

  • gpgcheck=0, setenforce 0, unsigned rebase as a default, firewall off
  • New vendor hostname, Flathub/Snap, or a store “to make it work”
  • Default-off Safe Browsing or fwupd
  • Secrets / cosign.key in the tree; pull_request_target; auto-merge
  • Deleting canary needles to pass CI

Every new overlay lock needs a ujust revert. If it weakens a lock, it is opt-in and must warn. Fill the PR template. Use the issue forms (overlay bug vs lock idea). Stock kernel bugs go upstream.

Public mark

Every overlay file under files/ and recipes/ must carry UNWOKE-SHIPPED-FIRST and the MIT copyright line. Compose, inspect, and the PR gate fail if a new file is unmarked. Do not obfuscate. Do not change the license. Ideas on their tracker stay public; copies of this tree must keep the notice. Ledger: Shipped first.

Tell people automatically

Pages rebuilds Home “What’s new”, the Compared ledger, and Changelog highlights from main. You do not edit those tables by hand for ordinary work. Factory-only commits (CI pins, snapshot hashes) stay off the human lists.

If the git subject is not enough, add three lines to the commit body. They become the Compared row:

People: Easy sentence a daily user should read.
Vs: How this is stricter or easier than stock.
Where: Pages now / Next overlay bake / USB ISO

Seed for older history: docs/_tools/people-seed.json. Toggles on Features stay a written spec (wrong automation would lie). Stock GitHub issues that map to a revertable overlay ujust are listed on Workarounds at Pages deploy — never applied to a bake.
