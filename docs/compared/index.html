Compared to stock

This page is the living list of how Unwoke is stricter, easier, or not better than official secureblue. The four-column table stays on Features. When we ship something, it gets a line here.

Not affiliated. We overlay their already-signed images. Kernel, SELinux, hardened_malloc, firewall, USBGuard, run0 — that is still them. We did not rewrite the OS.

Checking last green bake…

Easy words

Stock is a locked-down Fedora Atomic desktop with Trivalent and a curated store (Bazaar). Unwoke is that same OS with different house rules and a first-day conversation.

  • Same foundation. Their signed image, their kernel hardening, their SELinux. We layer on top. Not a fork.
  • No curator store. Bazaar / GNOME Software / Discover are gone. Flathub is off until you turn verified apps on. That is a security choice, not a missing package.
  • More things start off. Bluetooth, brew, toolbox, camera/mic, extra daemons. You turn on only what you need.
  • The first hour talks to you. Stock dumps you into a hardened desktop and a wiki. We open Unwoke setup, nag until the signed update is actually booted, and map “this is broken” to “this is a lock.”
  • Recommended default is Trivalent. Same jail as stock, plus extra policies. Origin and browserless stay as named choices. Stock only ships Trivalent.

The one sentence people get wrong. Default Origin images are not a tighter browser than stock + Trivalent. No Vanadium patches, fat brave_t. For the same house browser as stock, plus extra locks: rebase to *-trivalent.

Scorecard

House rules

Stricter by default

No store. Flathub/brew/BT/toolbox/camera off. Flatpak lockdown on. Extra Chromium packs on Origin and Trivalent flavors. Wheel off the greeter after a daily user exists.

First days

Easier to live with

Setup window, app-grid launcher, ujust why, tutorials, signed-reboot nag, three-question install picker, leftover stock steps in one menu. Same locks, less “is it broken?”

Factory

We watch the oven

Canary on their signed base, pin digest, inspect every flavor, twice-daily rebuild. ISO and Pages have their own alarms. Canary hits and new keys still need a human. Full map: Factory.

Browser

Recommended = Trivalent

Stock’s jail plus extra reversible policies. Origin is still an unsuffixed GHCR name if you want Brave Origin on purpose. Browserless is for no image browser.

Factory (you never see this, you still benefit)

The living map of auto-heal vs human gates is Factory. Short version:

  • Download their public key, check it still matches our copy, cosign verify the base, pin the digest so :latest cannot swap mid-build.
  • Canary: crane-export the signed base (do not run it, do not docker-pull it). If it names this repo, our GHCR, or /usr/share/unwoke, the overlay does not bake.
  • Inspect every published flavor: our signature, right browser binary, no leftover Trivalent on Origin/browserless, store launchers hidden, setup files present. Every vendors{} key must have a search launcher and offline help.
  • One GitHub issue per lane (overlay, ISO, Pages, vendors), plus nags for still-private GHCR, a rotated stock key, or a missing titanoboa pin. Overlay green does not close an ISO fail.
  • Vendor-watch: live checksums. Allowlisted HTTPS URL moves are committed automatically. New host / Flathub / gpgcheck=0 still open an issue.
  • Canary hits, a new keys/secureblue.pub, and titanoboa pin bumps are not auto-merged. That is the security boundary.

Stock cannot push to ghcr.io/sergi270710267. After the signed reboot, your PC follows our key, not theirs.

Where stock still wins

  • If you pick Origin anyway. Unsuffixed names are still Brave Origin (no Vanadium, fat brave_t). The recommended default is *-trivalent. Origin remains for people who want that browser on purpose.
  • No extra userns domain on stock. Origin adds brave_t to the userns allow-list. Trivalent and browserless flavors do not.
  • Their ISO download site is still nicer. isos.secureblue.dev is a picker with torrents. Ours is GHCR -iso + a 14-day Actions artifact (~4 GB). Stock’s ISO remains a valid fallback, then rebase. Enroll their Secure Boot key. Not Ventoy.
  • Their docs and community. We mirror their pages daily. Canonical is still secureblue.dev.
  • We are one person’s overlay. Their project is bigger. That is not a security feature for us; it is honesty.
