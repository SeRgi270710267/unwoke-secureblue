Install

Already on secureblue (or any Fedora Atomic): rebase, reboot, then reboot once more into the signed image. Empty-disk ISO steps are still their install docs (mirrored daily). After rebase, their post-install still applies.

Pick an image

1. First rebase

This switch cannot check our stamp yet (your PC does not have our key):

rpm-ostree rebase ostree-unverified-registry:ghcr.io/sergi270710267/unwoke-silverblue:latest
systemctl reboot

2. Signed deployment

After that reboot, a first-boot service queues the signed image. Reboot one more time when rpm-ostree status shows a staged signed deployment (or after a few minutes on the network). From then on, updates must match our cosign.pub.

If it did not auto-stage (no network on first boot):

rpm-ostree rebase ostree-image-signed:docker://ghcr.io/sergi270710267/unwoke-silverblue:latest
systemctl reboot

Empty disk

Flash a secureblue ISO first. Encrypt the drive, join wheel, enroll their Secure Boot key when prompted, then run the rebase commands above. We do not ship a daily ISO as a GitHub release (they are ~3 GB). Optional ISO artifacts can be built from the repo’s iso workflow.

Do not use Ventoy for the secureblue installer ISO. Enable Secure Boot, update the BIOS, and set a BIOS password if you care about that threat model — same advice as their install page.

After install

Stock secureblue post-install still applies. Full overlay + their steps: Post-install. Their page only (mirrored daily): secureblue/post-install.

Overlay extras (defaults are already on except Bubblejail and allow-browsers):

ujust unwoke-status
ujust audit-unwoke

To loosen a default, see Post-install. ujust set-allow-browsers on ALLOW is browserless only and stays off until you opt in.

Verify an image

cosign verify --key cosign.pub ghcr.io/sergi270710267/unwoke-silverblue
