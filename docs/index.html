Not affiliated with secureblue. This is a personal overlay on their signed images. Stock secureblue is at secureblue.dev.

What it is

A daily BlueBuild overlay on official secureblue Fedora Atomic images. Kernel hardening, SELinux, hardened_malloc, and their ujust commands stay. Trivalent and Bazaar are gone. There is no GUI software store.

The browser is the standalone Brave Origin RPM (brave-origin), not full brave-browser. User namespaces stay off for unconfined apps; Brave Origin runs in its own brave_t domain so its Chromium sandbox can start.

Install

Already on secureblue or Fedora Atomic:

rpm-ostree rebase ostree-unverified-registry:ghcr.io/sergi270710267/unwoke-silverblue:latest
systemctl reboot

After that reboot, first-boot stages the signed image. Reboot once more. KDE: unwoke-kinoite. NVIDIA: add -nvidia-open.

Toggles

All stock secureblue ujust commands still work. Overlay extras:

ujust unwoke-status
ujust audit-unwoke
ujust set-brave-hardening on
ujust set-brave-jitless on

Honest limits

  • This is not as locked down as stock secureblue + Trivalent.
  • Brave Origin is not Trivalent. No Vanadium-style Chromium patches, no tight Trivalent SELinux jail.
  • Signing key is a GitHub secret, not a hardware key.
