Donate

Not to us. Unwoke SecureBlue has no Open Collective, no GitHub Sponsors, no Monero QR, no Coinbase checkout, no Discord “sponsor” role. Price is $0. Forever. If someone DMs you an “Unwoke” wallet, it is a scam.

We do this for nothing

This overlay layers house rules on images they already signed (no curator store, extra default-off locks, a setup window). That is a git repo and a GitHub Actions minute bill. It is not a startup. There is no rainy-day fund. If GitHub stops being free, we cope or we stop. We will not invoice you for the privilege of ujust set-allow-browsers.

They, meanwhile, have a donate page. Open Collective. GitHub Sponsors. Monero. Coinbase. So they can pay builders and survive if GitHub changes the free-compute policy. A project that ships a custom Chromium and a curated store then passes the hat is allowed to do that. It is also allowed to look a bit rich asking for cash while the overlay that rips the curator out stays unpaid on purpose.

If you still want to pay someone: pay them

Every address and sponsor button we show is secureblue’s. Funds go to their mission (Trivalent, Bazaar, their CI, their domain). Not this overlay. We mirror the page so you can see the wallets without wondering if we swapped the QR.
