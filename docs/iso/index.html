USB downloads

These files are on this site only, after the same login as the rest of the docs. They are not a public release and not an Actions artifact.

The free store holds 9 GB. A stick is about 4 GB, so only the two recommended Trivalent images are here: GNOME and KDE, no NVIDIA. NVIDIA, Brave Origin, and browserless are not offered as ISOs. Install those with rebase.

GNOME · Trivalent

unwoke-silverblue-trivalent

Download ISO SHA256SUMS SHA256SUMS.sig

KDE · Trivalent

unwoke-kinoite-trivalent

Download ISO SHA256SUMS SHA256SUMS.sig

Check, then flash

Put the three files in one folder. The ISO must stay named latest.iso. That is the name inside SHA256SUMS. cosign.pub is in the public repository.

cosign verify-blob --key cosign.pub --insecure-ignore-tlog --signature SHA256SUMS.sig SHA256SUMS
sha256sum -c SHA256SUMS

--insecure-ignore-tlog skips the public log. It does not skip the signature. Then follow Install: flash, boot, and start Install Unwoke SecureBlue.

A missing file means that stick has not been published yet, or it was over 4.5 GB and was left off so the store stays inside 9 GB.
