Anonymity

Whonix, already configured the hard way

OpenPGP required KVM not VirtualBox Official images. Their Gateway/Internal nets. Clipboard, USB passthrough, and mic off so the host cannot correlate you. Start order is Gateway, then Workstation. Not Qubes. Not Tails.

Host stays Unwoke. Do not Tor the host. Do not enable a host VPN kill-switch while these VMs run. Do not log into the same accounts in Trivalent on the host. Work inside Workstation.

  1. Install (asked)

    ujust install-whonix

    Layers Fedora KVM if needed (reboot, run again). Downloads the pinned archive from download.whonix.org. Refuses if Patrick Schleizer’s fingerprint is not 916B8D99C38EAF5E8ADC7A2A8D66066A2EEACCDA. Unpacks, imports qemu:///session, hardens XML.

  2. Start

    ujust start-whonix

    Or the Whonix (Unwoke) icon. Refuses to start if Workstation grew extra NICs.

  3. Inside the Workstation

    Use Tor Browser there. Updates: Whonix’s own. Default user is passwordless per their docs — change that in the VMs.

Highest anonymity on Unwoke is this. Highest anywhere is still Qubes-Whonix (different OS). Hotel PC / no disk trace is still Tails.
