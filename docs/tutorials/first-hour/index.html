Start

The first hour

Keep locked The overlay is strict on purpose. A quiet desktop with no store, no Bluetooth, and no Flathub is the healthy state — not a failed install.

Secure default. Option 1 in setup: keep all defaults. Do the leftover stock steps (their key, kargs, USBGuard) without turning overlay locks off.

  1. Finish the signed reboot

    The first rebase cannot check our stamp yet. After that boot, a service stages ostree-image-signed. A notification and the MOTD say so. Reboot once more. Until then, updates are not locked to cosign.pub.

    rpm-ostree status
ujust setup

    In Unwoke setup (app grid, or ujust setup): Reboot now. The nag repeats every login and every 15 minutes until you reboot, with a Reboot button on the notification. If nothing staged, wait on the network or run the signed rebase from Install.

  2. Use the setup window — do not hunt a wiki

    First graphical login opens Unwoke setup (also in the app grid). Same stamps as ujust setup. Later, ujust why if something looks broken. Tutorial buttons open these pages. Nothing turns off until you pick it.

  3. Keep defaults unless you have a named need

    Flathub, brew, Bluetooth, toolbox, camera, JIT, WebGL, Bubblejail, extra daemons: all intentional. If a site or headset is the actual task, open that tutorial — do not flip everything “to make it normal.”

  4. Do their leftover steps

    Setup option 4, or their page: enroll the secureblue Secure Boot key (prompt password secureblue), ujust set-kargs-hardening if you rebased instead of using their ISO, then USBGuard. Full text: their post-install.

  5. Confirm the overlay

    ujust unwoke-status
ujust audit-unwoke
ujust audit-secureblue

Before the greeter, an installer-style screen asks for a daily (non-wheel) username. That is admin-split, not a hung install. The greeter does not start until you finish or skip. Empty name, Cancel, or a 5-minute skip leaves the lock pending — then Unwoke setup → Daily user is the graphical path. We do not let wheel onto the greeter first; that would be a weaker split.
