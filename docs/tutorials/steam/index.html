Games

Steam without skipping the locks

Asked, not silent Same command as stock: ujust install-steam. Same package: Flathub com.valvesoftware.Steam (not verified). On Unwoke that command asks before touching overlay locks. Stock’s script would just turn on unfiltered Flathub and leave games broken.

Secure default. If you never install Steam, leave Flathub off and lockdown on. Search “Steam” in the app grid to open this wizard. Nothing is flipped unless you say yes.

  1. Run the wizard

    ujust install-steam

    Or Unwoke setup → Steam. Required: unfiltered Flathub (full). Steam is not on the verified subset.

  2. What we ask (Unwoke extras vs stock)

    • Per-app Steam grants (net, library, GPU, pads, audio) while other Flatpaks stay locked — default yes
    • Global Flatpak lockdown off — default no
    • Global Flatpak Pulse/PipeWire record — default no (per-app audio is enough for games)
    • Allow exec on /tmp, /dev/shm, /var/tmp (Proton/Wine) — default no
    • Camera/mic hardware (Steam Voice) — default no
    • Bluetooth (wireless controllers) — default no
    • Xwayland — same question stock asks, default no

  3. Leftover stock, not overlay

    32-bit games: their kargs-32bit. Anti-cheat / some mods: ujust set-anticheat-support. USB dongle blocked: leftover USBGuard. We do not silent-enable those.

  4. Put the locks back

    ujust setup
# You loosened
ujust set-flathub off
ujust set-flatpak-lockdown on
ujust set-ramdisk-exec off
