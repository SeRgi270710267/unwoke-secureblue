Brand

This is the default look on every Unwoke image after the next rebuild. Settings can change it. ujust set-unwoke-theme apply puts it back. The USB Anaconda installer (empty-disk ISO only) uses the same navy and accent: dark Adwaita, logo on the sidebar. Rebase has no Anaconda.

Unwoke SecureBlue

Unwoke is the modifier. SecureBlue is one word, S and B capped. Git and GHCR stay lowercase slugs.

Palette

Real blue, hue ~224. Not lime, not teal, not Bootstrap. Dark navy from Old Glory Blue. Warning amber stays for alerts only.

Desktop wallpaper

Shipped at /usr/share/backgrounds/unwoke/unwoke-desktop.jpg. GNOME schema default. KDE wallpaper plugin UnwokeSecureBlue.

Lock screen

GNOME has no classic screensaver. This image is the lock screen and idle lock (org.gnome.desktop.screensaver). Plasma uses it on the screen locker. Path: /usr/share/backgrounds/unwoke/unwoke-lock.jpg.

Accent

SurfaceWhat you get
GNOME Shell (top bar, overview) Named accent blue only. GNOME does not take a custom hex here.
GTK 3 / 4 apps Exact #3b6cff via /etc/gtk-4.0/gtk.css and gtk-3.
KDE Plasma AccentColor=59,108,255 in kdeglobals. Same blue.
This site / GDM Navy + #3b6cff. Login screen on GNOME uses the desktop wallpaper.

User extensions stay off (stock). There is no custom GNOME Shell theme. Dark style is default.

Put it back

ujust set-unwoke-theme apply

GNOME Settings and Plasma Appearance still override after that if you pick something else.
