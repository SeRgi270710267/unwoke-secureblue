Their GitHub

Shipped first

We watch official secureblue issues. Every ticket we shipped first stays on this page. Open ones stay until they ship. When they ship, the card moves and says they shipped after us. If we later copy their better patch, that is written here on purpose.

[FEAT] is a request, not a release. On their tracker that prefix means “please add this.” An open ticket means they have not shipped it. We already did. Closed after our date means they shipped later. Not affiliated. We do not auto-copy their patch.

The public mark

You cannot copyright “please default LUKS on.” Those sentences were already on their tracker. You can make a silent copy obvious. This mark is default-on, like the other overlay locks: bake fails if it is missing.

  • Dates. Git on main and this page. If they ship later, the card says after us.
  • Every overlay file. Scripts, units, drop-ins, desktop files, and share JSON carry UNWOKE-SHIPPED-FIRST plus the MIT copyright line. Compose stamps a forgotten file. Inspect and the PR gate fail if git is unmarked. Live Chromium/Brave/Trivalent managed policies do not get that string (no extra unrecognized policy, no extra browser uniqueness).
  • A file in the OS. /usr/share/unwoke/SHIPPED-FIRST.txt is the dated ledger. /usr/share/unwoke/NOTICE is the MIT reminder. Copy the overlay tree and those strings come along. Reimplement from scratch and they do not — then the dates still stand.
  • A signed receipt. GitHub Release tag receipt attaches the same ledger next to cosign.pub. Not the OS. Not the USB.
  • License. MIT, Copyright 2026 SeRgi270710267. Code copies must keep that notice. Ideas on their issue tracker were already public. We do not obfuscate and we do not change the license.

Plain text: SHIPPED-FIRST.txt.

What this list is not

We do not ship every request on their tracker. UKI, ARM, server images, kernel modules, TPM, and SELinux policy need their signed base — an overlay cannot honestly claim those. We also skip FEATs that would weaken the box (Safe Browsing off, unloading all audio, default system Flatpaks). Bugs that hit this overlay belong on Workarounds, not here.
