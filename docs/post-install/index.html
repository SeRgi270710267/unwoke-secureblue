Post-install

Same slot as on secureblue.dev. Do the overlay steps first, then theirs.

Unwoke SecureBlue

  1. After the first rebase reboot, wait until first-boot stages the signed image (rpm-ostree status). Reboot once more.
  2. Confirm the overlay:
ujust unwoke-status
ujust audit-unwoke
ujust audit-secureblue

Origin images (Brave Origin policies; restart the browser after):

ujust set-brave-hardening on
ujust set-brave-jitless on

Browserless images — host browsers stay blocked until you opt in:

ujust set-allow-browsers on ALLOW

Stock secureblue (mirrored)

You still do their post-install: enroll their Secure Boot key if the prompt did not appear, ujust set-kargs-hardening if you rebased instead of installing from their ISO, USBGuard, optional separate wheel account. Full text, updated daily from their repo:

Their post-install (mirrored)
